# Dropper

**Twitch Drops: Track and Redeem**

A Twitch Drops companion for tracking watch time, monitoring progress, managing eligible streams, and redeeming rewards.

## Current Release

**Dropper 2.5.0** is the standalone live-test build.

## Features

- Track Twitch Drop progress and credited watch time.
- Redeem completed Twitch Drops.
- Claim channel point bonus chests.
- Keep eligible streams active in the background.
- Maintain a standby stream queue and switch when progress stalls or a stream goes offline.
- View a compact Drop inventory and progress interface.
- Use background earning status, diagnostics, notifications, and update/changelog notices.
- Twitch-themed UI with dedicated Dropper icon and launcher assets.

## Installation

Install `dropper.user.js` with a compatible userscript manager.

Dropper requests access only to Twitch pages and `gql.twitch.tv` for Drop progress and claim operations.
